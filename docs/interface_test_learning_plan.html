每个文件怎么学

  1. 先看文件开头、fixture 和测试类名称，画出被测对象与外部依赖。
  2. 挑一个成功用例、一个失败用例，写下 输入 → mock/临时数据 → 执行 → 断言。
  3. 打开对应的 backend/app 生产代码，找到断言所覆盖的分支；分清测试替身和真实组件。
  4. 从 backend 目录单独运行该测试文件。最后用两三句话说明它防止了什么回归。

阅读重点：优先理解断言证明了什么，再研究 mock 的细节。长文件先按测试类或场景分两次阅读，不必一次读完所有用例。
